### Project Title
LeetCode SQL Aggregate Functions Practice

### Description
This project contains my solutions to SQL problems from LeetCode. It is included as a focused SQL practice project to reinforce skills in aggregation, conditional logic, date manipulation, and window functions.

### The problems included are:
- 1193 - Monthly Transactions I: conditional aggregation and grouping
- 1174 - Immediate Food Delivery II: identifying first orders and calculating percentages
- 550 - Game Play Analysis IV: first login dates and next-day activity
- 570 - Managers with at Least 5 Direct Reports: self-joins and grouping
- 1934 - Confirmation Rate: joins and conditional aggregation
- 1661 - Average Time of Process per Machine: window functions and time differences
- 1070 - Product Sales Analysis III: subqueries and finding first-year records
- 1045 - Customers Who Bought All Products: grouping and having with subqueries
- 1789 - Primary Department for Each Employee: conditional logic and self-joins
- 180 - Consecutive Numbers: window functions with lead/lag
- 1164 - Product Price at a Given Date: correlated subqueries and date comparisons
- 1204 - Last Person to Fit in the Bus: running totals with window functions
- 1907 - Count Salary Categories: conditional aggregation with UNION ALL
The problem statements and database schemas are provided by LeetCode. The SQL solutions in this repository are my own.

### Key Takeaways
These problems reinforced:
1. Aggregations and GROUP BY
2. CASE WHEN and conditional aggregation
3. JOIN and self-joins
4. CTEs and window functions
5. Date comparisons and date arithmetic
6. Percentage calculations and rounding
7. Correlated and non-correlated subqueries
8. UNION ALL for combining result sets
